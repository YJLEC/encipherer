# Encipherer v1.1.0 · 表格隐私卫士

完全离线的 Excel 表格脱敏/还原工具:把含隐私的表格脱敏后交给第三方或 AI,处理完一键还原原值。零网络请求、零安装、数据不出本机。

## 本版亮点

- **10 类 PII 脱敏**:手机号、身份证号、邮箱、银行卡号、IP、车牌、姓名、地址、学号、通用编码
- **学号脱敏**:保留入学年份(`2024…`/`24…` 开头),其余位混淆;不符合年份格式的编号做同长度字符集保真混淆
- **表头智能识别**:自动识别表头行(可手动指定),表头行不参与脱敏;扫描时按表头关键词给出类型建议
- **格式保真占位符**:假手机号合法号段、假身份证校验位正确、假银行卡过 Luhn、学号等长——人眼看自然,业务校验不报错
- **工作区加密**:PBKDF2(600k)派生密钥,映射表 AES-256-GCM 加密(`.ecw`);同一原值 → 同一占位符,跨文件跨会话稳定
- **智能还原**:按值而非位置匹配,第三方增删行列后仍可还原;未识别内容保持原样
- **可视化选区 + 自动扫描**;xlsx / xlsm / xls / csv(GBK 自适应);深色模式;自动锁定

## 校验下载完整性

```
# Windows (PowerShell)
Get-FileHash .\Encipherer-v1.1.0.html -Algorithm SHA256
# macOS / Linux
shasum -a 256 Encipherer-v1.1.0.html
```

与 `SHA256SUMS.txt` 中的值一致即为本项目原始产物。

## 隐离与安全

- 运行时零网络请求(页面 CSP `connect-src 'none'` 从浏览器层面禁死,可断网使用)
- 明文只存在于内存与你显式导出的文件;详见仓库 `docs/PRIVACY.md`

**注意**:主密码无法找回——忘记密码 = 该工作区的映射永久无法解密。请妥善保管密码与 `.ecw` 文件。
