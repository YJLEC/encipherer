# Encipherer v1.2.0 · 表格隐私卫士

## 本版更新:多行表头

表头从单行升级为**多行复选**:

- 工具条「🧭 表头」按钮改为弹层,内含**复选框列表**(前 10 行,每行附内容预览),可任意勾选多行(如"标题行 + 表头行");
- 勾选的所有表头行一律**不参与脱敏**(整列规则自动从最后一行表头之后开始,区域规则跨到表头行时自动跳过);
- 「自动识别」保留:自动命中单行表头(识别不了就当作无表头),需要多行时勾选即可;「自动识别」按钮可随时恢复默认;
- 自动扫描的表头关键词建议兼容多行:从勾选的表头行中逐行取列名匹配(学号/姓名/手机号等)。

```
# macOS / Linux
shasum -a 256 Encipherer-v1.2.0.html
```

## 功能全景

- **10 类 PII 脱敏**:手机号、身份证号、邮箱、银行卡号、IP、车牌、姓名、地址、学号、通用编码
- **学号脱敏**:保留入学年份(`2024…`/`24…`),其余混淆;非常规编号同长度字符集保真混淆
- **格式保真占位符**:假手机号合法号段、假身份证校验位正确、假银行卡过 Luhn——人眼看自然,业务校验不报错
- **工作区加密**:PBKDF2(600k) + AES-256-GCM;同一原值 → 同一占位符,跨文件跨会话稳定
- **智能还原**:按值匹配,第三方增删行列后仍可还原;未识别内容保持原样
- **可视化选区 + 自动扫描(值检测 + 表头关键词)**;xlsx / xlsm / xls / csv(GBK 自适应);深色模式;自动锁定
