# 隐私与安全白皮书(Encipherer 表格隐私卫士)

**版本:1.0 · 最后更新:2026-09-24**

## 一句话承诺

Encipherer 是一个**完全离线**运行的工具:它不发起任何网络请求、不内置任何遥测/统计/更新检查,你的表格数据、映射表与密码**不会离开你的电脑**。

---

## 1. 运行形态与数据流

| 形态 | 说明 |
|---|---|
| 单文件 HTML(`Encipherer.html`) | 双击在本地浏览器打开,全部代码与依赖内嵌于这**一个文件**中,可整体审计 |
| Electron 桌面版 | 同一套代码装进离线桌面壳,同样不联网 |

数据处理全程发生在浏览器内存中:

```
你的 Excel 文件 ──(File API 读入内存)──> 解析为内存数据结构
                ──> 脱敏/还原计算(内存)
                ──> 生成结果文件(内存 Blob)
                ──(浏览器"另存为/下载")──> 你的磁盘
```

**没有任何一步经过网络。** 页面通过 CSP(`connect-src 'none'`)在浏览器层面禁止了对外连接,代码本身也不含 `fetch`/`XMLHttpRequest`/`WebSocket`。

## 2. 密码与密钥

- 你为每个"工作区"设置一个**主密码**。
- 主密钥派生:**PBKDF2-HMAC-SHA256,600,000 次迭代**,16 字节随机盐。
- 主密钥再经 HKDF-SHA256 派生三把用途隔离的子钥:
  - `kMap`:HMAC-SHA256,用于**确定性**生成占位符(同一原值永远得到同一占位符);
  - `kStore`:AES-256-GCM,加密工作区文件;
  - `kCheck`:密码校验子。
- 密钥**不可导出**(WebCrypto non-extractable),只存在于内存;锁定或关闭工作区后即被丢弃。
- 主密码本身**绝不存储**,任何文件中都找不到它。

## 3. 工作区文件(.ecw)里有什么

`.ecw` = 一行 JSON 头(明文,仅含:格式版本、工作区名称、盐、迭代次数、密码校验子、时间戳)+ AES-256-GCM 密文(完整映射表与设置)。

- **明文头不含任何隐私数据**;名称是你自己填的工作区名,介意可填无意义名字。
- 密文使用 AES-256-GCM(含认证标签):没有主密码无法解密;篡改会解密失败。
- 校验子可被用于离线暴力破解尝试——这是所有密码保护系统的共性,600,000 次迭代使每次猜测成本极高。请使用**长且唯一**的密码。

## 4. 数据留存在哪里

| 位置 | 内容 | 敏感度 |
|---|---|---|
| 内存 | 密钥、明文映射、表格内容 | 锁定/关闭后丢弃(交给 GC) |
| 浏览器 IndexedDB(仅本机) | 加密的 `.ecw` 副本(自动保存) | 加密,无密码不可读;可在"设置→数据"一键清除 |
| 浏览器 localStorage | 最近工作区**元数据**(名称/时间/是否有副本) | 不含映射与任何隐私值;销毁工作区时一并清除 |
| 你的下载目录 | 你主动导出的脱敏表 / 还原表 / `.ecw` / 明文映射 CSV | 由你掌控;明文映射 CSV 导出时有醒目警告 |

**注意**:浏览器本身(历史记录、缓存)不会记录你的表格内容;但操作系统休眠文件/内存转储理论上可含内存快照,高敏感环境请参考第 6 节。

## 5. 威胁模型

**防护**:
- 第三方(或 AI 服务)只拿到脱敏副本,看不到任何原始隐私值;
- `.ecw` 或 IndexedDB 被他人拷走 → 无主密码不可解密;
- 处理方回传的表格被改动(增删行列、改列顺序)→ 智能还原按**值**而非位置匹配,仍可还原;
- 占位符格式保真(假手机号仍是合法手机号形态),不暴露"哪行是谁"的额外信息。

**不防护(请自行注意)**:
- 主密码被窃取或被肩窥;
- 你主动导出**明文映射 CSV** 并外发;
- 脱敏副本中的**非选中区域**(工具只处理你指定的行列,请用"自动扫描+预览"检查覆盖面);
- 格式本身的信息泄漏:占位符与原值**一一对应**,若第三方已知某占位符对应的真人,该列其余占位符的对应关系并不因此暴露(每个值的替换相互独立);
- 极端本地取证(内存转储、休眠文件)。

## 6. 最佳实践建议

1. 每个外发项目使用**独立工作区**,项目结束即销毁;
2. 主密码 ≥ 12 位,不与其他账户复用;
3. 打开"自动锁定"(默认 10 分钟);
4. `.ecw` 与明文映射**绝不与脱敏副本放在一起**传输或存储;
5. 外发前用"预览效果"快速检查一遍;
6. 高敏环境:用完关闭浏览器(彻底释放内存),或使用桌面版并在结束后退出。

## 7. 可审计性

单文件版的全部逻辑(含第三方库 SheetJS/ExcelJS)都在 `Encipherer.html` 一个文件里,任何有能力的工程师都可以全文检查;也可断网使用——功能不受任何影响。
